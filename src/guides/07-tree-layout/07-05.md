# 07-05 자식 추가 후 재배치

## 학습 목표
실행 중 노드를 추가한 뒤 트리 전체를 다시 배치합니다.

## 사용 API
- `Diagram.addItem`
- `createDiagramLink`
- `Diagram.arrange`

## 구현 순서
초기 5개 노드를 배치하고 버튼을 누르면 새 자식과 연결선을 추가한 후 동일한 레이아웃을 다시 적용합니다.

## 실행 결과
버튼 실행 전 5개, 실행 후 6개 노드가 겹침 없이 재정렬됩니다.

## 검증 기준
추가 후 노드 6개, 연결선 5개가 모두 visible이어야 합니다.

## 활용
서버 데이터나 사용자 입력으로 트리가 변경되는 화면에 같은 패턴을 적용할 수 있습니다.
