# 08-06 특정 깊이까지만 펼치기

## 학습 목표
트리를 순회하며 지정한 깊이까지만 노드와 연결선을 표시합니다.

## 사용 API
- `outgoingLinks`
- `destination`
- 깊이 우선 재귀 순회

## 구현 순서
루트를 깊이 1로 시작해 자식으로 이동할 때 깊이를 1씩 증가시킵니다. 현재 깊이가 제한 이하인 노드만 표시하고, 다음 단계로 이어지는 연결선은 제한 미만일 때만 표시합니다.

## 실행 결과
“2단계까지만 펼치기”를 누르면 루트와 두 자식만 보이고 3단계 손자는 숨겨집니다.

## 검증 기준
전체 노드 7개·연결선 6개 중 visible 노드 3개·연결선 2개, expanded 노드 1개여야 합니다.

## 활용
트리 규모에 따라 첫 화면의 탐색 범위를 제한하면서 데이터 객체는 그대로 유지할 수 있습니다.
