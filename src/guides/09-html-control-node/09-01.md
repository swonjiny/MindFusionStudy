# 09-01 HTML 텍스트만 표시

## 목표

`ControlNode.template`에 HTML 문자열을 지정하고, React 래퍼가 만든 실제 코어
`DiagramView`를 생성자에 전달합니다.

## 핵심 순서

1. React `DiagramView`에 ref를 연결합니다.
2. `onControlLoaded`에서 `ref.current.find()`로 코어 View를 얻습니다.
3. `new ControlNode(coreView)`로 노드를 만듭니다.
4. `template`과 `bounds`를 지정한 뒤 Diagram에 추가합니다.
5. `onNodeDomCreated`에서 `getContent()`로 실제 HTML을 확인합니다.

## 주의점

`new ControlNode(diagram)`은 현재 설치된 코어 4.9.1의 생성자 계약과 다릅니다.
렌더 중에는 ref가 아직 없으므로 반드시 View 로드 이후에 생성해야 합니다.

## 정상 결과

- ControlNode 1개
- 연결선 0개
- `[data-mf-html-node="09-01"]` DOM 1개
- 콘솔 오류 0개
