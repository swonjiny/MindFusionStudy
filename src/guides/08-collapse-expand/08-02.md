# 08-02 모든 하위 노드 재귀 접기

## 학습 목표
직접 자식뿐 아니라 손자 이하의 모든 하위 노드와 연결선을 재귀적으로 숨깁니다.

## 사용 API
- `outgoingLinks`
- `DiagramLink.destination`
- 재귀 함수

## 구현 순서
현재 노드의 각 outgoing link를 순회하며 destination에 같은 함수를 먼저 호출한 후 노드와 링크를 숨깁니다.

## 실행 결과
루트 아래의 자식·손자가 한 번에 접히고 루트만 표시됩니다.

## 검증 기준
전체 노드 5개·연결선 4개는 유지되고 visible 노드 1개·연결선 0개, expanded 노드 0개여야 합니다.

## 주의
트리가 아닌 순환 그래프에 적용할 때는 방문한 노드를 기록해 무한 재귀를 방지해야 합니다.
