# 02-01 일반 노드 1개 생성

## 1. 학습 목표

ShapeNode 하나를 직접 생성하고 위치, 크기, 텍스트와 기본 스타일을 설정한다.

## 2. 완성 화면

연한 파란 배경, 파란 테두리와 `일반 노드` 텍스트를 가진 노드 한 개가 중앙 부근에 표시된다.

## 3. 선수 지식

01 단계의 Diagram/DiagramView 관계와 React effect 정리 방식을 이해해야 한다.

## 4. 이번 단계에서 사용하는 객체

`Diagram`, `ShapeNode`, `Rect`, `DiagramView`를 사용한다.

## 5. 핵심 개념

직접 만든 ShapeNode는 `bounds`를 지정하고 `diagram.addItem(node)`로 등록해야 화면에 나타난다.

## 6. 파일 구성

`Step0201SingleNode.jsx`가 독립 진입점이고 `lessonDefinitions.js`의 `directNode`가 실제 생성과 스타일을 담당한다.

## 7. 구현 순서

Diagram 초기화 → ShapeNode 생성 → Rect 지정 → text/brush/stroke 지정 → addItem → 노드 수 검증 순서다.

## 8. 전체 소스 코드

```js
const node = new ShapeNode(diagram);
node.bounds = new Rect(55, 42, 55, 28);
node.text = "일반 노드";
node.brush = "#e8f3ff";
node.stroke = "#2877de";
diagram.addItem(node);
```

## 9. 소스 코드 상세 설명

생성자의 Diagram 인자는 기본 속성을 복사할 부모다. 화면 등록은 생성자와 별개이므로 addItem이 필요하다.

## 10. 실행 흐름

메뉴 선택 → 독립 예제 mount → clearAll → 노드 생성/등록 → DiagramView repaint → 검증 보고 순서다.

## 11. 상태와 데이터 흐름

Diagram이 노드 객체를 보관하며 `diagram.nodes.length`가 검증 패널의 현재 값이 된다.

## 12. 정상 실행 기준

노드 1개, 연결선 0개, 파란 계열 스타일, 텍스트 표시, 콘솔 오류 0개여야 한다.

## 13. 자동 검증 방법

`verification-2` 항목이 success이고 상세 값이 현재 1개인지 확인한다.

## 14. 수동 확인 항목

노드를 마우스로 드래그할 수 있고 테두리와 텍스트가 선명한지 확인한다.

## 15. 자주 발생하는 오류

`addItem`을 빼면 객체는 만들어졌지만 Diagram 컬렉션과 화면에 나타나지 않는다.

## 16. 오류 해결 과정

객체 생성, bounds, addItem, nodes.length 순서로 값을 확인하고 canvas 크기도 함께 점검한다.

## 17. 이전 단계와 비교

01-03의 빈 Diagram에 처음으로 ShapeNode 데이터 한 개를 추가했다.

## 18. 다음 단계

## 20. 핵심 요약
