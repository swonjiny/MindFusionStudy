## 최종 통합 구조

- `useIntegratedDiagram`: Diagram 생성, 선택, 트리 가시성, 뷰포트, 검색·필터를 한곳에서 관리한다.
- `integratedData`: JSON과 비동기 Mock API 데이터 소스를 제공한다.
- `integratedTemplates`: ControlNode HTML과 카드 크기 계산을 재사용한다.
- `IntegratedDiagramExample`: 15~19 메뉴가 같은 구현을 옵션별로 조합한다.
- 각 단계 JSX는 외부에서 가져다 쓸 수 있는 독립 진입 컴포넌트이며, 통합 단계는 표시된 공통 모듈과 함께 복사한다.

## 검증 범위

- 노드·연결선 수와 visible 상태
- 선택 이벤트와 카드 확장·클릭
- 재귀 및 전체 접기·펼치기
- 중심 이동, 확대·축소, 화면 맞춤
- 검색·필터 결과
- JSON·Mock API의 성공·로딩·오류·빈 상태
- 실제 ControlNode HTML DOM
- 브라우저 콘솔 오류
- Playwright 종합 시나리오와 최종 화면 캡처

## 제한사항

- Mock API는 교육용 Promise 기반 구현이며 실제 원격 서버나 영속 저장소를 사용하지 않는다.
- 검색과 필터는 현재 로드된 로컬 데이터셋을 대상으로 한다.
- MindFusion과 UI 라이브러리가 포함되어 프로덕션 JavaScript 번들 크기 경고가 발생한다.
- ControlNode의 HTML은 브라우저 DOM 오버레이이므로 캔버스 전용 내보내기 기능에서는 별도 합성 처리가 필요하다.
