# 09-03 HTML 이미지 표시

## 목표

ControlNode 안에 실제 `<img>` 요소를 렌더링합니다.

## 구현

예제의 이미지는 SVG data URI입니다. 외부 URL이나 프로젝트 이미지 경로가 없어서 소스 파일을
다른 React 프로젝트로 복사해도 깨지지 않습니다. `alt` 텍스트와 `object-fit: cover`도 함께 지정합니다.

Overview나 NodeListView는 ControlNode의 HTML 대신 이미지를 그릴 수 있으므로, 그런 화면까지
사용할 때는 data URI가 특히 안전합니다.

## 정상 결과

- 실제 `<img data-testid="control-image">` DOM 1개
- ControlNode 1개, 연결선 0개, 콘솔 오류 0개
