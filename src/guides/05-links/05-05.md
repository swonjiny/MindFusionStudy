# 05-05 연결선 모양과 스타일 비교

## 학습 목표
`LinkShape`와 `DashStyle`을 조합해 관계 유형을 시각적으로 구분합니다.

## 사용 API
- `LinkShape.Bezier`
- `LinkShape.Cascading`
- `DashStyle.Dash`

## 구현
첫 연결선은 파란 Bezier 곡선, 두 번째는 주황 Cascading 점선과 삼각형 머리를 사용합니다.

## 실행 결과
같은 Diagram에서 곡선과 직각형 경로의 차이를 비교할 수 있습니다.

## 검증 기준
노드 3개, 연결선 2개, 콘솔 오류 0개여야 합니다.

## 설계 팁
모양뿐 아니라 색상·점선·텍스트를 함께 사용하면 의미 구분이 더 명확해집니다.

## 범위 종료
이 예제가 2차 개발의 마지막입니다. 06 이후 메뉴는 구현하지 않습니다.
