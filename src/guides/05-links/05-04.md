# 05-04 화살표 머리 설정

## 학습 목표
`ArrowHeads` 프리셋과 크기로 연결 방향을 표시합니다.

## 사용 API
```js
link.headShape = ArrowHeads.Triangle();
link.headShapeSize = 5;
```

## 실행 결과
출발에서 도착으로 향하는 빨간 선 끝에 삼각형 화살표가 표시됩니다.

## 검증 기준
노드 2개와 연결선 1개가 생성되고 방향 표시가 보여야 합니다.

## 선택지
설치 버전은 `Triangle`, `Circle`, `Arrow`, `None` 등의 팩토리를 제공합니다.

## 주의점
선 굵기와 화살표 크기의 비율을 함께 조절해야 합니다.

## 다음 단계
연결선 모양과 점선 스타일을 비교합니다.
