# 03-02 글꼴 스타일 설정

## 학습 목표
설치된 drawing 패키지의 `Font`를 사용해 노드별 글꼴을 구성합니다.

## 사용 API
- `new Font(name, size, bold)`
- `node.font`

## 구현
```js
node.font = new Font("Arial", 16, true);
```

## 실행 결과
Regular 12와 Bold 16 텍스트를 한 화면에서 비교합니다.

## 검증 기준
노드 2개와 연결선 0개가 유지되고 굵은 글꼴이 시각적으로 구분되어야 합니다.

## 주의점
브라우저에 없는 글꼴은 시스템 대체 글꼴로 렌더링됩니다.
