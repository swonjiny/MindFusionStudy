# 04-04 선택 변경 이벤트

## 학습 목표
`onSelectionChanged`에서 선택 전후의 항목 목록을 확인합니다.

## 이벤트 API
- `SelectionChangedEventArgs.oldItems`
- `SelectionChangedEventArgs.newItems`

## 구현
콜백에서 이전 개수와 새 개수를 이벤트 로그에 기록하고 현재 `selection.nodes`도 확인합니다.

## 실행 방법
단일 선택, 두 노드 선택, 선택 해제를 차례로 실행해 변화를 비교합니다.

## 검증 기준
노드 3개, 연결선 0개, 이벤트 횟수 1 이상이어야 합니다.

## 주의점
선택을 연속으로 추가하면 항목마다 이벤트가 발생할 수 있습니다.
