# 15-01 메타정보가 있는 루트 노드

## 목표

4차 ControlNode HTML 방식과 5차 명함 카드 템플릿을 결합해 이미지·제목·설명·메타정보가 있는 루트 노드를 만듭니다.

## 재사용 구조

얇은 단계 컴포넌트는 공통 `IntegratedDiagramExample`에 `root` 변형만 전달합니다. 실제 HTML은
`rootNodeHtml`, 크기는 `cardBounds`, Diagram 생명주기는 `useIntegratedDiagram`이 담당합니다.

루트 선택 시 같은 템플릿 함수가 3개의 명함형 카드를 포함한 확장 HTML을 만들며, 별도 구현으로 분기하지 않습니다.

## 검증

루트 노드 1개, HTML DOM 1개, 데이터 준비 상태와 콘솔 오류 0개를 확인합니다.
