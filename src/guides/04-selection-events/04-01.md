# 04-01 노드 클릭 이벤트

## 학습 목표
React `DiagramView`의 `onNodeClicked` 콜백에서 클릭된 노드를 확인합니다.

## 이벤트 API
콜백의 `NodeEventArgs.node`가 실제 `ShapeNode`를 가리킵니다.

## 구현
```jsx
<DiagramView onNodeClicked={(_, args) => recordEvent("클릭", args.node)} />
```

## 실행 방법
실행 화면의 노드 A 또는 노드 B를 한 번 클릭합니다.

## 검증 기준
이벤트 횟수가 1 이상이고 마지막 이벤트에 노드 텍스트가 표시되어야 합니다.

## 주의점
빈 캔버스 클릭은 노드 클릭 이벤트가 아닙니다.
