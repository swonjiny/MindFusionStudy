# 13-05 카드 내부 버튼으로 펼치기·닫기

## 목표

노드를 직접 선택하는 대신 축약 카드 내부의 **펼치기** 버튼으로 카드 목록을 열고,
펼쳐진 상태 상단의 **닫기** 버튼으로 원래 크기를 복원합니다.

## 축약 상태

최초에는 `data-expanded="false"`인 작은 카드가 표시됩니다. 카드 내부에 `data-action="expand"`와
`data-interactive="true"`가 지정된 펼치기 버튼이 있어 노드 이동과 버튼 입력을 구분합니다.

## 펼친 상태

펼치기 버튼을 누르면 노드 크기를 확장하고 13-04에서 사용한 다음 카드 다섯 개를 그대로 표시합니다.

- 민트 · UI 설계
- 라온 · 시각화
- 하루 · UX 연구
- 소담 · 콘텐츠
- 노을 · 접근성

상단에는 `data-action="close"`인 닫기 버튼이 표시됩니다. 닫기 버튼을 누르면 카드 DOM을 제거하고
축약 HTML과 원래 `Rect` 크기를 복원합니다.

## 이벤트 위임

펼치기와 닫기 과정에서 내부 HTML 전체가 교체되므로, 교체되지 않는 ControlNode 콘텐츠 컨테이너에
하나의 클릭 리스너를 등록합니다. 클릭한 요소의 `data-action`을 확인해 펼침과 닫힘을 구분하며,
컴포넌트 제거 시 리스너도 해제합니다.

## 확인

1. 최초에는 펼치기 버튼 한 개와 축약 카드가 보여야 합니다.
2. 펼치기 버튼을 누르면 13-04와 동일한 카드 다섯 개가 표시되어야 합니다.
3. 펼친 카드 상단에 닫기 버튼이 있어야 합니다.
4. 닫기 버튼을 누르면 카드 목록이 사라지고 원래 크기로 돌아와야 합니다.
