# 07-03 가로 트리 자동 배치

## 학습 목표
같은 트리를 왼쪽에서 오른쪽 방향으로 배치합니다.

## 사용 API
- `LayoutDirection.LeftToRight`
- `TreeLayout.direction`

## 구현 순서
세로 배치 예제에서 방향만 `LeftToRight`로 변경하고 레이아웃을 다시 적용합니다.

## 실행 결과
루트가 왼쪽에, 세 자식이 오른쪽에 세로로 정렬됩니다.

## 검증 기준
노드 4개, 연결선 3개가 visible이며 루트가 expanded 상태여야 합니다.

## 활용
가로 공간이 넓은 조직도나 프로세스 탐색 화면에 적합합니다.
