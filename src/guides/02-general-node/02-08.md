# 02-08 노드 텍스트 표시

## 1. 학습 목표

ShapeNode의 한글 text, textColor, fontSize를 설정한다.

## 2. 완성 화면

파란 글자색과 큰 글자 크기로 `한글 텍스트`가 표시된다.

## 3. 선수 지식

노드 생성과 bounds 설정, CSS 색상 문자열 형식을 알아야 한다.

## 4. 이번 단계에서 사용하는 객체

`ShapeNode.text`, `ShapeNode.textColor`, `ShapeNode.fontSize`를 사용한다.

## 5. 핵심 개념

노드 텍스트는 canvas에 그려지므로 DOM 텍스트가 아니다. 글자색과 배경색의 대비를 확보해야 한다.

## 6. 파일 구성

`Step0208NodeText.jsx` 하나가 텍스트 속성과 DiagramView 렌더링을 모두 담는다.

## 7. 구현 순서

노드 생성 → text 지정 → textColor 지정 → fontSize 지정 → bounds로 공간 확보 순서다.

## 8. 전체 소스 코드

```js
node.text = "한글 텍스트";
node.textColor = "#1456b8";
node.fontSize = 14;
```

## 9. 소스 코드 상세 설명

text는 JavaScript UTF-16 문자열이므로 별도 인코딩 변환 없이 한글을 사용할 수 있다.

## 10. 실행 흐름

스타일 setter가 노드의 텍스트 visual을 갱신하고 DiagramView가 canvas를 다시 그린다.

## 11. 상태와 데이터 흐름

문자열과 스타일 값은 ShapeNode 속성에 저장된다. React DOM에는 노드 텍스트가 별도 요소로 생기지 않는다.

## 12. 정상 실행 기준

한글이 깨지지 않고 파란색 14 크기로 보이며 노드 수는 1이어야 한다.

## 13. 자동 검증 방법

canvas 내부 텍스트를 DOM으로 직접 찾지 않고 검증 패널의 노드 수와 콘솔 오류를 확인한다.

## 14. 수동 확인 항목

한글 자소가 깨지지 않고 배경과 글자 대비가 충분한지 확인한다.

## 15. 자주 발생하는 오류

textColor가 배경과 같거나 fontSize가 너무 작으면 값은 있어도 보이지 않는 것처럼 느껴진다.

## 16. 오류 해결 과정

임시로 검정 textColor와 큰 fontSize를 적용하고 bounds도 넓혀 원인을 분리한다.

## 17. 이전 단계와 비교

02-07까지는 geometry가 중심이었고 이번 단계부터 텍스트 visual을 다룬다.

## 18. 다음 단계

02-09에서 줄바꿈 문자와 더 큰 bounds로 여러 줄 텍스트를 표시한다.

## 19. 연습 문제

영문, 숫자와 이모지를 섞은 텍스트를 넣어 폰트 fallback 결과를 확인한다.

## 20. 핵심 요약

text, textColor, fontSize는 노드 내부 canvas 텍스트를 결정하며 배경 대비와 공간이 중요하다.
