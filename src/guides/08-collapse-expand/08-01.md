# 08-01 자식과 연결선 함께 접기

## 학습 목표
부모를 접을 때 직접 자식뿐 아니라 자식으로 향하는 연결선도 함께 숨깁니다.

## 사용 API
- `ShapeNode.expanded`
- `ShapeNode.outgoingLinks`
- `DiagramItem.visible`

## 구현 순서
부모의 `expanded`를 false로 바꾸고, 각 outgoing link와 그 destination 노드의 `visible`을 false로 설정합니다.

## 실행 결과
버튼을 누르면 부모만 남고 두 자식과 두 연결선이 동시에 사라집니다.

## 검증 기준
전체 노드 3개·연결선 2개는 유지되지만 visible 노드 1개·연결선 0개, expanded 노드 0개가 됩니다.

## 핵심 포인트
항목을 삭제하지 않으므로 다시 펼칠 때 같은 객체와 데이터를 재사용할 수 있습니다.
