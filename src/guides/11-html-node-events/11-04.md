# 11-04 컴포넌트 제거 시 이벤트 해제

## 목표

예제 컴포넌트가 메뉴 이동 등으로 제거될 때 직접 연결한 DOM 이벤트를 모두 해제합니다.

## 구현

등록 시 `Map<Element, handler>`에 저장합니다. `useEffect` cleanup은 모든 항목에 대해
`removeEventListener('click', handler)`를 호출하고 Map과 Diagram을 비웁니다.

React 래퍼가 코어 DiagramView를 dispose하더라도 애플리케이션이 직접 등록한 DOM handler의
생명주기는 애플리케이션이 관리하는 편이 명확하고 안전합니다.

## 자동 검증

Playwright가 버튼 클릭을 확인한 뒤 다른 메뉴로 이동하고, cleanup 실행 횟수가 1인지 검사합니다.
