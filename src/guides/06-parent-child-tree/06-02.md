# 06-02 자식 2개

## 학습 목표
하나의 부모가 여러 자식을 가질 수 있는 기본 분기를 구성합니다.

## 사용 API
- `ShapeNode`
- `Diagram.factory.createDiagramLink`
- `outgoingLinks`

## 구현 순서
부모 1개와 자식 A·B를 만든 후 동일한 부모에서 두 연결선을 생성합니다.

## 실행 결과
부모 아래에 두 자식이 좌우로 분기됩니다.

## 검증 기준
노드 3개, 연결선 2개가 모두 visible이고 부모 1개가 expanded 상태여야 합니다.

## 확장 방법
같은 패턴으로 자식 배열을 순회하면 자식 수를 쉽게 늘릴 수 있습니다.
