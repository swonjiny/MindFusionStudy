# 03-03 텍스트 외곽선

## 학습 목표
배경 위에서 텍스트 가독성을 높이기 위해 외곽선 색상과 두께를 지정합니다.

## 사용 API
- `node.textStroke`
- `node.textStrokeThickness`

## 구현
```js
node.textColor = "#ffffff";
node.textStroke = "#274c77";
node.textStrokeThickness = 1;
```

## 실행 결과
기본 텍스트와 흰색 글자·파란 외곽선 텍스트가 나란히 표시됩니다.

## 검증 기준
노드 2개, 연결선 0개, 콘솔 오류 0개여야 합니다.

## 주의점
외곽선이 너무 두꺼우면 작은 글자 내부가 뭉개질 수 있습니다.
