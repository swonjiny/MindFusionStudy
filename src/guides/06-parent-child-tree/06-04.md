# 06-04 손자 노드 추가

## 학습 목표
자식 노드가 다시 부모 역할을 하는 손자 구조를 만듭니다.

## 사용 API
- `DiagramLink.origin`
- `DiagramLink.destination`
- `ShapeNode.outgoingLinks`

## 구현 순서
루트에 자식 A·B를 연결하고, 자식 A에서 손자 A-1·A-2로 연결합니다.

## 실행 결과
루트, 자식, 손자의 3개 깊이가 화면에 나타납니다.

## 검증 기준
노드 5개, 연결선 4개가 visible이며 하위 항목이 있는 노드 2개가 expanded여야 합니다.

## 핵심 포인트
모든 관계를 부모에서 자식 방향으로 통일하면 재귀 탐색이 단순해집니다.
