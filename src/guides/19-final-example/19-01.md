# 19-01 최종 종합 조직 탐색기

## 포함 기능

15~18의 동일 공통 훅과 템플릿을 한 화면에서 활성화합니다. 별도의 최종 전용 Diagram 생성 코드는 없습니다.

- 이미지·제목·설명·메타정보 루트
- 선택 시 담당자 카드 3개 표시 및 카드 선택
- 자식·손자 트리와 재귀/전체 접기·펼치기
- 선택 중심 이동, 확대·축소, 화면 맞춤
- 검색, 유형 필터, 선택 상세 패널
- JSON/Mock API 기반 데이터 모델
- 데이터·HTML·노드·연결선·콘솔 자동 검증

## 사용 순서

루트를 선택해 카드를 펼치고, 카드를 클릭합니다. 검색과 필터로 범위를 좁힌 뒤 전체 펼치기로 복원합니다.
도구 모음으로 선택 가지를 접거나 화면을 맞추고 오른쪽 상세 패널에서 선택 정보를 확인합니다.

## 정상 결과

초기 노드 10개와 연결선 9개, 루트 HTML 1개가 표시됩니다. 모든 상호작용 후 콘솔 오류는 0개여야 합니다.
