# 10-02 버튼 DOM 검색

## 목표

생성된 ControlNode 콘텐츠에서 버튼 DOM을 안전한 시점에 찾습니다.

## 구현 순서

1. `onNodeDomCreated`를 받습니다.
2. `args.node.getContent()`로 콘텐츠 루트를 얻습니다.
3. `querySelector('[data-control-action="confirm"]')`로 버튼을 찾습니다.
4. 검색 성공 여부를 화면과 검증 패널에 반영합니다.

렌더 직후나 노드 추가 직전에 검색하면 DOM이 아직 없을 수 있으므로 `nodeDomCreated`가 기준입니다.

## 정상 결과

`querySelector로 버튼 DOM 검색 성공`이 표시되고 버튼 DOM 수가 1개입니다.
