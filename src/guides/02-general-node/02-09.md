# 02-09 여러 줄 텍스트 표시

## 1. 학습 목표

줄바꿈이 포함된 긴 텍스트와 노드 크기의 관계를 이해한다.

## 2. 완성 화면

보라색 노드 안에 세 줄의 텍스트가 중앙 정렬되어 표시된다.

## 3. 선수 지식

02-08의 text와 fontSize 설정, 02-07의 크기 설정을 알아야 한다.

## 4. 이번 단계에서 사용하는 객체

`ShapeNode.text`, `ShapeNode.bounds`, 기본 텍스트 레이아웃을 사용한다.

## 5. 핵심 개념

문자열의 `\n`은 명시적 줄바꿈이다. 노드의 height가 부족하면 텍스트가 잘리거나 촘촘해질 수 있다.

## 6. 파일 구성

`Step0209MultilineText.jsx`와 `lessonDefinitions.js` 02-09 case가 핵심이다.

## 7. 구현 순서

충분히 큰 Rect 생성 → 줄바꿈 문자열 지정 → fontSize 설정 → 중앙 정렬 확인 순서다.

## 8. 전체 소스 코드

```js
node.bounds = new Rect(45, 30, 75, 48);
node.text = "첫 번째 줄\n두 번째 줄\n세 번째 줄";
node.fontSize = 12;
```

## 9. 소스 코드 상세 설명

명시적 줄바꿈은 단어 자동 줄바꿈과 다르다. 3줄을 예상하므로 height를 단일 줄 예제보다 키웠다.

## 10. 실행 흐름

text setter → 줄 단위 레이아웃 계산 → bounds 안에서 정렬 → canvas 렌더링 순서다.

## 11. 상태와 데이터 흐름

여러 줄도 하나의 문자열로 저장되며 별도 React 배열 상태는 필요 없다.

## 12. 정상 실행 기준

세 줄 모두 노드 안에 읽기 쉽게 보이고 노드 수 1, 오류 0이어야 한다.

## 13. 자동 검증 방법

노드 존재와 오류 없음은 자동 검증하고 줄바꿈 모양은 스크린샷 또는 수동 확인한다.

## 14. 수동 확인 항목

첫 줄과 마지막 줄이 테두리에 닿거나 잘리지 않는지 확인한다.

## 15. 자주 발생하는 오류

JavaScript 문자열에 실제 `\n` 대신 두 문자 `\\n`을 넣으면 줄이 바뀌지 않는다.

## 16. 오류 해결 과정

문자열 길이, 개행 코드, node.bounds.height와 fontSize를 차례로 확인한다.

## 17. 이전 단계와 비교

02-08의 단일 줄 텍스트에 개행과 더 큰 height를 추가했다.

## 18. 다음 단계

## 19. 연습 문제

두 문장짜리 긴 텍스트에서 자동 줄바꿈과 명시적 개행을 비교한다.

## 20. 핵심 요약
