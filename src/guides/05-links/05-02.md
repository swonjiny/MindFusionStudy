# 05-02 연결선 2개 생성

## 학습 목표
입력 → 처리 → 출력 흐름을 두 개의 연결선으로 표현합니다.

## 구현 순서
노드 세 개를 생성한 뒤 첫째-둘째, 둘째-셋째 쌍으로 `createDiagramLink`를 호출합니다.

## 실행 결과
세 단계가 좌에서 우로 이어진 간단한 프로세스가 표시됩니다.

## 검증 기준
노드 3개와 연결선 2개가 정확히 생성되어야 합니다.

## 데이터 관점
`diagram.nodes.length`와 `diagram.links.length`를 각각 독립적으로 검증합니다.

## 주의점
초기화 시 `clearAll()`을 호출해 재실행 후 중복 연결선이 생기지 않게 합니다.
