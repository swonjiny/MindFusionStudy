# 14-04 카드 클릭과 선택 스타일

## 목표

카드 클릭 이벤트와 시각적 선택 상태, 키보드 입력을 함께 구현합니다.

## 구현 포인트

- 카드에 `data-interactive="true"`, `role="button"`, `tabindex="0"`을 지정합니다.
- 클릭 또는 Enter/Space 입력 시 기존 카드 스타일을 초기화하고 대상 카드만 강조합니다.
- 선택 카드에는 `aria-pressed="true"`, 파란 테두리와 배경을 적용합니다.
- 등록한 click·keydown handler는 cleanup에서 모두 해제합니다.

## 검증

카드 한 장을 클릭하면 선택 카드 수 1, 이벤트 수 1, 강조 스타일과 상태 문구가 갱신됩니다.
