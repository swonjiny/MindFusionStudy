# 07-02 트리 간격 조정

## 학습 목표
레벨 간격과 같은 레벨의 노드 간격을 각각 조절합니다.

## 사용 API
- `TreeLayout.levelDistance`
- `TreeLayout.nodeDistance`

## 구현 순서
자식 5개 트리를 만든 후 `levelDistance`는 42, `nodeDistance`는 26으로 설정합니다.

## 실행 결과
노드가 겹치지 않고 넓은 간격으로 배치됩니다.

## 검증 기준
노드 6개와 연결선 5개가 모두 visible이어야 합니다.

## 설계 팁
노드 텍스트가 길거나 자식 수가 많을수록 `nodeDistance`를 늘립니다.
