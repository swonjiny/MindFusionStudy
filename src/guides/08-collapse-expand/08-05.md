# 08-05 전체 펼치기

## 학습 목표
접혀 있는 모든 가지를 한 번에 펼쳐 전체 구조를 복원합니다.

## 사용 API
- `Diagram.nodes`
- `Diagram.links`
- `visible`, `expanded`

## 구현 순서
모든 노드와 연결선의 visible을 true로 바꾸고, 자식이 있는 노드의 expanded를 true로 설정합니다.

## 실행 결과
처음에는 루트만 보이며 버튼을 누르면 6개 노드와 5개 연결선이 모두 나타납니다.

## 검증 기준
visible 노드 6개, visible 연결선 5개, expanded 부모 노드 3개여야 합니다.

## 주의
기존의 부분 접힘 상태를 보존해야 한다면 전체 펼치기 대신 08-03의 상태 저장 방식을 사용합니다.
