# 07-01 세로 트리 자동 배치

## 학습 목표
`TreeLayout`으로 루트에서 아래 방향의 트리를 자동 배치합니다.

## 사용 API
- `TreeLayout`
- `LayoutDirection.TopToBottom`
- `Diagram.arrange(layout)`

## 구현 순서
노드와 연결선을 먼저 만든 뒤 방향과 간격을 지정한 레이아웃을 `arrange`에 전달합니다.

## 실행 결과
루트가 위에, 세 자식이 아래에 자동 정렬됩니다.

## 검증 기준
노드 4개, 연결선 3개가 visible이고 펼친 루트가 1개여야 합니다.

## 설치 주의
독립 프로젝트에서는 `@mindfusion/graphs`도 직접 설치해야 합니다.
