# 05-01 연결선 1개 생성

## 학습 목표
두 노드 사이에 `DiagramLink` 한 개를 생성합니다.

## 사용 API
```js
const link = diagram.factory.createDiagramLink(origin, destination);
```

## 등록 규칙
Factory 메서드가 반환한 연결선은 이미 Diagram에 등록되므로 `addItem`을 다시 호출하지 않습니다.

## 실행 결과
시작 노드와 도착 노드 사이에 연결선이 표시됩니다.

## 검증 기준
노드 2개, 연결선 1개, 콘솔 오류 0개여야 합니다.

## 주의점
origin과 destination은 같은 Diagram에 등록된 노드여야 합니다.
