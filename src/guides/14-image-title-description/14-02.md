# 14-02 이미지 오류 대체 처리

## 목표

프로필 이미지 로드가 실패해도 빈 이미지 표시 대신 이니셜 대체 이미지를 제공합니다.

## 구현

`nodeDomCreated`에서 이미지의 `error` 이벤트를 연결한 다음 실패 데이터를 설정합니다.
handler는 SVG data URI 대체 이미지를 적용하고 상태를 갱신합니다. 컴포넌트 cleanup에서는
같은 handler 참조로 이벤트를 해제합니다.

## 검증

`data-fallback="true"`, 대체 이미지 표시 문구, 카드 DOM 1개와 콘솔 오류 0개를 확인합니다.
