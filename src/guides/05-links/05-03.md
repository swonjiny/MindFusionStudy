# 05-03 연결선 텍스트 표시

## 학습 목표
`DiagramLink.text`로 두 노드의 관계를 설명합니다.

## 사용 API
```js
link.text = "승인 요청";
link.stroke = "#2877de";
```

## 실행 결과
주문과 결제 노드 사이의 선 위에 승인 요청 문구가 표시됩니다.

## 검증 기준
노드 2개와 텍스트가 있는 연결선 1개가 생성되어야 합니다.

## 가독성
연결선 길이가 너무 짧으면 텍스트와 노드가 겹칠 수 있으므로 충분한 간격을 둡니다.

## 주의점
연결선 텍스트와 노드 텍스트는 서로 독립적인 속성입니다.
