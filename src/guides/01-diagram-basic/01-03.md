# 01-03 Diagram 배경색 설정

## 1. 학습 목표

`diagram.backBrush`와 호스트 CSS 배경을 구분하고 연한 격자 배경을 만든다.

## 2. 완성 화면

연한 파란 바탕 위에 일정한 22px 격자가 표시되고 빈 Diagram 안내가 겹쳐 보인다.

## 3. 선수 지식

01-01의 모델/뷰 관계와 CSS 다중 `linear-gradient` 문법을 알고 있으면 좋다.

## 4. 이번 단계에서 사용하는 객체

`Diagram.backBrush`, `DiagramView.showGrid`, `.diagram-grid` CSS 클래스를 사용한다.

## 5. 핵심 개념

MindFusion 배경은 Diagram 렌더링 계층에 속하고 CSS 배경은 canvas를 감싼 HTML 호스트 계층에 속한다. 목적에 맞게 선택한다.

## 6. 파일 구성

`Step0103DiagramBackground.jsx`, `lessonDefinitions.js`, `diagram.css`가 이 단계의 핵심 파일이다.

## 7. 구현 순서

1. 초기화에서 `diagram.backBrush`를 지정한다.
2. DiagramView에 `showGrid`를 전달한다.
3. 호스트에 `diagram-grid` 클래스를 준다.
4. 두 방향의 linear-gradient로 격자를 만든다.
5. 노드 수 0을 검증한다.

## 8. 전체 소스 코드

```js
diagram.backBrush = "#ffffff";
```

```css
.diagram-grid {
  background-image:
    linear-gradient(rgba(72,112,155,.1) 1px, transparent 1px),
    linear-gradient(90deg, rgba(72,112,155,.1) 1px, transparent 1px);
  background-size: 22px 22px;
}
```

## 9. 소스 코드 상세 설명

첫 gradient는 가로선, 두 번째는 세로선을 만든다. 낮은 alpha를 사용해 노드보다 배경이 더 강해지지 않게 한다.

## 10. 실행 흐름

lessonKey 확인 → Diagram 배경 지정 → CSS 클래스 적용 → canvas와 호스트 합성 순서로 화면이 보인다.

## 11. 상태와 데이터 흐름

배경은 시각 설정이고 노드 데이터에는 영향을 주지 않는다. 검증 상태의 nodeCount와 linkCount는 계속 0이다.

## 12. 정상 실행 기준

격자가 일정하고 배경이 밝으며 안내 문구를 방해하지 않아야 한다. 콘솔 오류가 없어야 한다.

## 13. 자동 검증 방법

01-03 메뉴 선택 후 실행 영역과 검증 패널의 0개 값을 확인한다. CSS 시각 결과는 스크린샷으로 보조 검증한다.

## 14. 수동 확인 항목

확대/축소 때 CSS 격자는 화면 픽셀 기준으로 고정된다는 점을 확인한다.

## 15. 자주 발생하는 오류

canvas가 불투명 배경으로 호스트 전체를 덮으면 호스트의 CSS 격자가 보이지 않을 수 있다.

## 16. 오류 해결 과정

배경을 어느 계층에서 책임지는지 하나씩 끄며 확인하고 필요하면 MindFusion `showGrid`를 우선 사용한다.
