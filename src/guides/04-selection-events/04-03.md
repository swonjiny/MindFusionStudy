# 04-03 다중 노드 선택

## 학습 목표
다중 선택을 허용하고 여러 `ShapeNode`를 Selection에 추가합니다.

## 사용 API
```js
diagram.allowMultipleSelection = true;
await diagram.selection.addItem(first);
await diagram.selection.addItem(second);
```

## 실행 방법
`두 노드 선택` 버튼을 눌러 앞의 두 노드를 선택합니다.

## 검증 기준
노드 3개, 연결선 0개, 선택 노드 2개가 표시되어야 합니다.

## 선택 해제
`selection.clear()`로 모든 선택을 한 번에 제거할 수 있습니다.

## 주의점
다중 선택 허용이 꺼져 있으면 마지막 항목만 남을 수 있습니다.
