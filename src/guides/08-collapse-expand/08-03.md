# 08-03 기존 펼침 상태 복원

## 학습 목표
접기 전의 visible·expanded 상태를 저장하고 같은 상태로 되돌립니다.

## 사용 API
- `useRef`
- `DiagramItem.visible`
- `ShapeNode.expanded`

## 구현 순서
접기 전에 모든 노드의 visible·expanded와 모든 링크의 visible 값을 저장합니다. 복원 시 저장된 값을 각 원본 객체에 다시 대입합니다.

## 실행 결과
임시 접기 후 복원 버튼을 누르면 자식·손자와 연결선, 펼침 표시가 원래대로 돌아옵니다.

## 검증 기준
복원 후 visible 노드 4개, visible 연결선 3개, expanded 노드 2개여야 합니다.

## 핵심 포인트
단순히 모두 펼치는 방식과 달리 사용자가 일부 가지만 접어둔 상태도 정확히 복원할 수 있습니다.
