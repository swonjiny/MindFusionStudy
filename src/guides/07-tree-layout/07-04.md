# 07-04 3단계 자동 배치

## 학습 목표
여러 분기를 가진 3단계 구조를 수동 좌표 없이 정렬합니다.

## 사용 API
- `TreeLayout`
- `Diagram.arrange`
- `levelDistance`, `nodeDistance`

## 구현 순서
본부·팀·업무 노드를 연결한 후 한 번의 `arrange` 호출로 전체 트리를 배치합니다.

## 실행 결과
7개 노드가 깊이에 따라 3개 행으로 정렬됩니다.

## 검증 기준
노드 7개, 연결선 6개가 visible이며 부모 역할의 3개 노드가 expanded여야 합니다.

## 핵심 포인트
레이아웃은 연결 방향에서 계층을 계산하므로 링크 방향을 일관되게 유지합니다.
