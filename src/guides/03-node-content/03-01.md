# 03-01 텍스트 여백 설정

## 학습 목표
`ShapeNode.textPadding`에 `Thickness`를 지정해 텍스트와 테두리 사이의 간격을 제어합니다.

## 사용 API
- `new Thickness(all)` 또는 `new Thickness(left, top, right, bottom)`
- `node.textPadding`

## 구현
```js
node.textPadding = new Thickness(10, 8, 10, 8);
```

## 실행 결과
동일한 크기의 두 노드에서 기본 여백과 넓은 여백을 비교할 수 있습니다.

## 검증 기준
노드 2개, 연결선 0개이며 콘솔 오류가 없어야 합니다.

## 주의점
여백이 지나치게 크면 텍스트 영역이 작아져 줄바꿈이나 잘림이 발생합니다.
