# 06-01 부모 1개와 자식 1개

## 학습 목표
가장 작은 트리인 부모 1개, 자식 1개, 연결선 1개를 만듭니다.

## 사용 API
- `ShapeNode`
- `createDiagramLink(parent, child)`
- `expandable`, `expanded`

## 구현 순서
부모와 자식 노드를 만든 뒤 부모를 origin, 자식을 destination으로 연결합니다. 하위 항목이 있는 부모만 펼침 가능한 노드로 표시합니다.

## 실행 결과
부모에서 자식으로 향하는 2노드 트리가 표시됩니다.

## 검증 기준
전체·visible 노드 2개, 전체·visible 연결선 1개, 펼친 부모 1개, 콘솔 오류 0개입니다.

## 핵심 포인트
연결 방향이 이후 재귀 탐색과 트리 배치의 부모·자식 기준이 됩니다.
