# 06-05 3단계 트리 완성

## 학습 목표
1단계 루트, 2단계 분기, 3단계 리프가 있는 균형 트리를 완성합니다.

## 사용 API
- `ShapeNode.expandable`
- `ShapeNode.expanded`
- `createDiagramLink`

## 구현 순서
루트 아래에 두 개의 중간 노드를 만들고, 각 중간 노드에 두 개의 리프를 연결합니다.

## 실행 결과
총 7개 노드와 6개 연결선으로 이루어진 3단계 트리가 표시됩니다.

## 검증 기준
전체 항목이 visible이고 루트와 중간 노드 3개가 expanded 상태여야 합니다.
