# 11-01 HTML 버튼 클릭 이벤트

## 목표

ControlNode 내부의 세 버튼에 서로 다른 표준 DOM `click` 이벤트를 연결합니다.

- **선택**: 현재 선택한 버튼이 무엇인지 알려줍니다.
- **상태 확인**: 노드가 정상적으로 실행 중이라는 메시지를 표시합니다.
- **도움말**: 메시지를 다시 숨기는 방법을 안내합니다.

## 메시지 토글

버튼은 `data-button-id`와 `data-message`로 기능과 메시지를 구분합니다. 버튼을 누르면 노드 내부의
`role="status"` 요소에 해당 메시지가 나타납니다. 같은 버튼을 다시 누르면 메시지가 사라집니다.
다른 버튼을 누르면 기존 메시지를 새 버튼의 메시지로 교체합니다.

각 버튼의 `aria-pressed` 값도 함께 변경하므로 현재 선택된 버튼을 보조 기술에서도 확인할 수 있습니다.

## 이벤트 등록과 해제

`nodeDomCreated`에서 세 버튼을 검색하고 각각 `addEventListener`를 호출합니다. 버튼과 handler 쌍은
`Map`에 보관하며, 컴포넌트가 제거될 때 같은 함수 참조로 `removeEventListener`를 호출합니다.

## 확인

1. 세 버튼이 모두 실제 HTML DOM으로 표시되어야 합니다.
2. 각 버튼을 누르면 서로 다른 메시지가 노드 내부에 표시되어야 합니다.
3. 같은 버튼을 연속으로 두 번 누르면 메시지가 숨겨져야 합니다.
4. 다른 버튼을 누르면 활성 버튼과 메시지가 함께 변경되어야 합니다.
