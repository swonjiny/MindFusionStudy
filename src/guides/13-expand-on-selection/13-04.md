# 13-04 카드 수 기반 크기 계산

## 목표

카드 수를 입력으로 노드 너비와 높이를 계산하고 선택 시 적용합니다.

```js
const sizeFor = (count) => ({
  width: 96 + Math.min(count, 3) * 10,
  height: 18 + count * 18,
});
```

5개 카드의 계산 결과는 `126 × 108`입니다. 축약 상태에서는 작은 고정 크기를 사용하고
선택된 경우에만 계산 크기를 적용합니다.

## 검증

선택 1개, 확장 true, 카드 DOM 5개와 계산 결과 문구를 확인합니다.
