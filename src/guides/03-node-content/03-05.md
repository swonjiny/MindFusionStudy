# 03-05 텍스트에 맞춰 크기 조정

## 학습 목표
`resizeToFitText`와 `FitSize`로 텍스트 길이에 맞는 노드 크기를 계산합니다.

## 사용 API
- `node.resizeToFitText(FitSize.KeepHeight)`
- `FitSize.KeepHeight`

## 구현 순서
노드를 Diagram에 추가하고 텍스트를 설정한 뒤 `resizeToFitText`를 호출합니다.

## 실행 결과
고정 크기 노드와 높이를 유지하면서 너비가 늘어난 노드를 비교합니다.

## 검증 기준
노드 2개와 연결선 0개가 생성되고 맞춤 노드의 텍스트가 보여야 합니다.

## 주의점
폰트와 패딩을 먼저 정해야 최종 측정값이 정확합니다.
