# 10-01 HTML 버튼 모양

## 목표

ControlNode 템플릿 안에 실제 `<button>`을 만들고 스타일을 적용합니다.

## 핵심

버튼에는 `type="button"`과 `data-interactive="true"`를 지정합니다. 후자가 없으면 Diagram이
마우스 입력을 노드 이동 입력으로 처리할 수 있습니다. 이 단계는 모양과 DOM 존재만 검증하며
클릭 로직은 아직 연결하지 않습니다.

## 정상 결과

- ControlNode 1개, HTML 루트 1개, 버튼 DOM 1개
- 연결선 0개, 콘솔 오류 0개
