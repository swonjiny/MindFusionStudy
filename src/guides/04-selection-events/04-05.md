# 04-05 노드 더블 클릭 이벤트

## 학습 목표
`onNodeDoubleClicked`로 노드의 더블 클릭 동작을 분리합니다.

## 구현
```jsx
<DiagramView onNodeDoubleClicked={(_, args) => recordEvent("더블 클릭", args.node)} />
```

## 실행 방법
노드 중앙을 빠르게 두 번 클릭합니다.

## 검증 기준
마지막 이벤트에 `더블 클릭`과 노드 텍스트가 표시되어야 합니다.

## 이벤트 설계
실제 앱에서는 상세 편집 열기처럼 단일 클릭과 충돌하지 않는 동작에 연결합니다.

## 주의점
브라우저와 운영체제의 더블 클릭 간격 설정에 영향을 받습니다.
