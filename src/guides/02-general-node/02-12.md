# 02-12 노드 테두리 변경

## 1. 학습 목표

테두리 색상, 두께와 선 스타일을 설치된 API로 설정한다.

## 2. 완성 화면

기본 실선, 굵은 실선, 점선 테두리의 세 노드가 표시된다.

## 3. 선수 지식

02-11의 brush/stroke 색상 조합과 노드 생성 패턴을 알아야 한다.

## 4. 이번 단계에서 사용하는 객체

`stroke`, `strokeThickness`, `strokeDashStyle`, `DashStyle.Solid`, `DashStyle.Dash`를 사용한다.

## 5. 핵심 개념

stroke는 색, strokeThickness는 폭, strokeDashStyle은 패턴을 각각 책임진다.

## 6. 파일 구성

`Step0212NodeBorder.jsx`, `lessonDefinitions.js`, `@mindfusion/drawing`의 DashStyle import가 핵심이다.

## 7. 구현 순서

세 노드 생성 → stroke 지정 → thickness 지정 → DashStyle 지정 → 시각 비교 → 3개 검증 순서다.

## 8. 전체 소스 코드

```js
node.stroke = "#d97706";
node.strokeThickness = 2;
node.strokeDashStyle = DashStyle.Dash;
```

## 9. 소스 코드 상세 설명

현재 4.9.1/4.4.0 선언 파일은 strokeDashStyle과 DashStyle의 Solid, Dash, Dot 등을 제공한다.

## 10. 실행 흐름

각 테두리 속성 설정 → pen visual 갱신 → 지정 굵기와 dash 배열로 canvas stroke 순서다.

## 11. 상태와 데이터 흐름

테두리 속성은 각 ShapeNode에 독립 저장되며 선택 여부와 관계없는 기본 모양이다.

## 12. 정상 실행 기준

세 노드의 테두리 모양이 구분되고 노드 수 3, 연결선과 오류 0이어야 한다.

## 13. 자동 검증 방법

노드 수와 오류를 자동 검증하고 선 패턴은 수동 또는 스크린샷으로 확인한다.

## 14. 수동 확인 항목

점선이 실선과 구분되고 굵은 선이 노드 텍스트 영역을 침범하지 않는지 확인한다.

## 15. 자주 발생하는 오류

CSS `borderStyle`을 노드에 적용하거나 문자열 `"dashed"`를 strokeDashStyle에 넣으면 기대대로 동작하지 않는다.

## 16. 오류 해결 과정

DashStyle import와 실제 enum 값을 확인하고 우선 Solid에서 시작해 Dash로 변경한다.

## 17. 이전 단계와 비교

02-11은 내부 채우기, 이번 단계는 외곽선의 세 속성을 분리해 제어한다.

## 18. 다음 단계

이번 1차 범위는 여기까지다. 일반 노드 내부 콘텐츠와 HTML 노드는 사용자 지시 전까지 구현하지 않는다.

## 19. 연습 문제

Dot, DashDot, 사용자 지정 dash array를 조사하고 지원 범위를 비교한다.

## 20. 핵심 요약

테두리는 stroke, strokeThickness, strokeDashStyle의 조합이며 enum 지원 여부를 설치 버전에서 확인해야 한다.
