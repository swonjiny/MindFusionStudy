# 04-02 단일 노드 선택

## 학습 목표
`diagram.selection`을 통해 선택 상태를 코드로 제어합니다.

## 사용 API
- `selection.clear()`
- `await selection.addItem(node)`
- `selection.nodes`

## 실행 방법
`첫 노드 선택` 버튼을 누르면 기존 선택을 지우고 첫 노드를 선택합니다.

## 검증 기준
노드 2개, 연결선 0개, 선택 노드 1개이며 선택 변경 이벤트가 발생해야 합니다.

## 비동기 처리
`addItem`은 Promise를 반환하므로 완료를 기다린 뒤 상태를 검증합니다.

## 주의점
Diagram에 포함되지 않은 항목을 선택 대상으로 사용하지 않습니다.

다중 선택을 허용하고 두 노드를 함께 선택합니다.
