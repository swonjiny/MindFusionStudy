# 02-10 텍스트 정렬

## 1. 학습 목표

설치된 API의 `Alignment` 값으로 가로와 세로 정렬을 설정한다.

## 2. 완성 화면

왼쪽/위, 가운데, 오른쪽/아래 정렬을 가진 세 노드가 나란히 표시된다.

## 3. 선수 지식

02-08과 02-09의 텍스트 표시, 노드 크기와 padding 관계를 알아야 한다.

## 4. 이번 단계에서 사용하는 객체

`Alignment.Near`, `Alignment.Center`, `Alignment.Far`, `textAlignment`, `lineAlignment`를 사용한다.

## 5. 핵심 개념

textAlignment는 가로, lineAlignment는 세로 방향을 제어한다. CSS `text-align`을 canvas 노드에 적용하지 않는다.

## 6. 파일 구성

`Step0210TextAlignment.jsx` 안에서 세 노드의 정렬 값을 직접 비교한다.

## 7. 구현 순서

세 노드 생성 → 같은 크기 사용 → 각각 Near/Center/Far 지정 → 시각 비교 → 노드 수 3 검증 순서다.

## 8. 전체 소스 코드

```js
node.textAlignment = Alignment.Near;
node.lineAlignment = Alignment.Near;
```

## 9. 소스 코드 상세 설명

Near와 Far는 좌우/상하 의미를 방향에 맞게 해석하고 Center는 두 축의 중앙이다.

## 10. 실행 흐름

노드별 alignment 속성 저장 → 텍스트 layout rectangle 계산 → 지정 위치에 canvas 텍스트 렌더링 순서다.

## 11. 상태와 데이터 흐름

정렬은 각 ShapeNode의 독립 속성이다. 공통 Diagram이나 React 레이아웃 정렬과 무관하다.

## 12. 정상 실행 기준

세 노드의 텍스트 위치가 서로 다르고 노드 수 3, 연결선 0이어야 한다.

## 13. 자동 검증 방법

노드 수는 자동 검증하고 텍스트 정렬은 수동 확인 항목으로 분리한다.

## 14. 수동 확인 항목

Near 텍스트는 왼쪽 위, Far 텍스트는 오른쪽 아래, Center는 가운데인지 확인한다.

## 15. 자주 발생하는 오류

CSS 정렬 속성을 호스트에 주면 canvas 내부 노드 텍스트는 바뀌지 않는다.

## 16. 오류 해결 과정

노드의 실제 textAlignment와 lineAlignment 값을 확인하고 enum import 위치를 점검한다.

## 17. 이전 단계와 비교
