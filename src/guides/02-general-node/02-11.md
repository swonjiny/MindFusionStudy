# 02-11 노드 배경색 변경

## 1. 학습 목표

ShapeNode의 brush에 색상 문자열을 지정해 상태별 기본 배경을 표현한다.

## 2. 완성 화면

기본 파랑, 성공 초록, 주의 주황 배경을 가진 세 노드가 표시된다.

## 3. 선수 지식

노드 생성과 canvas 색상 렌더링, 접근 가능한 명도 대비 개념을 알아야 한다.

## 4. 이번 단계에서 사용하는 객체

`ShapeNode.brush`, `ShapeNode.stroke`, `ShapeNode.textColor`를 사용한다.

## 5. 핵심 개념

brush는 노드 내부 채우기다. 선택 상태와 무관한 기본 스타일을 먼저 명확하게 만든다.

## 6. 파일 구성

`Step0211NodeBackground.jsx`와 `lessonDefinitions.js`의 색상 배열이 핵심이다.

## 7. 구현 순서

세 노드 생성 → 상태 라벨 지정 → brush/stroke 조합 지정 → 대비 확인 → 3개 검증 순서다.

## 8. 전체 소스 코드

```js
node.brush = "#e8f8ef";
node.stroke = "#289766";
node.textColor = "#172033";
```

## 9. 소스 코드 상세 설명

연한 배경에는 짙은 텍스트를 사용한다. 테두리는 같은 계열의 더 진한 색으로 경계를 만든다.

## 10. 실행 흐름

스타일 속성 설정 → visual invalidation → 각 노드의 내부와 테두리 repaint 순서다.

## 11. 상태와 데이터 흐름

색상 값은 노드 객체에 저장되고 상태 의미는 text 라벨로 함께 전달된다.

## 12. 정상 실행 기준

서로 다른 세 색상, 읽을 수 있는 텍스트, 노드 수 3, 오류 0이어야 한다.

## 13. 자동 검증 방법

노드 개수와 오류는 자동 검증한다. canvas 픽셀 색상은 스크린샷으로 확인한다.

## 14. 수동 확인 항목

색상만으로 의미를 전달하지 않고 `기본`, `성공`, `주의` 라벨이 함께 보이는지 확인한다.

## 15. 자주 발생하는 오류

CSS `backgroundColor`를 ShapeNode에 적용하려 하면 노드 채우기가 바뀌지 않는다.

## 16. 오류 해결 과정

노드의 brush 값을 단순 hex 문자열로 바꿔 보고 테마나 선택 효과와 충돌하는지 확인한다.

## 17. 이전 단계와 비교

02-10은 텍스트 배치, 이번 단계는 노드의 면 채우기를 비교한다.

## 18. 다음 단계

02-12에서 테두리 색상, 두께와 DashStyle을 함께 설정한다.

## 19. 연습 문제

정보, 성공, 경고, 오류 네 상태 팔레트를 만들고 명도 대비를 비교한다.

## 20. 핵심 요약

노드 배경은 brush이며 텍스트, 테두리와 함께 일관된 상태 스타일을 구성해야 한다.
