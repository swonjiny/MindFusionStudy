# 12-01 명함형 카드 1개

## 목표

객체 한 건을 배열에 넣고 `map`으로 이미지·닉네임·간단소개 HTML을 만듭니다.

## 핵심 구현

- 데이터는 `{ id, nickname, intro, color }` 배열로 관리합니다.
- 이미지는 외부 파일이 필요 없는 SVG data URI로 생성합니다.
- `new ControlNode(viewRef.current.find())` 방식은 4차 조사에서 확정한 패턴입니다.
- `nodeDomCreated`에서 `[data-card-id]`를 검색해 실제 카드 DOM 수를 검증합니다.

## 정상 결과

노드 1개, 카드 데이터·DOM 각 1개, HTML 루트 1개, 콘솔 오류 0개입니다.
