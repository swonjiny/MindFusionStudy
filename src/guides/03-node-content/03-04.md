# 03-04 텍스트 자르기 비교

## 학습 목표
`clipText`가 긴 문자열을 노드 경계 안에서 처리하는 방식을 확인합니다.

## 사용 API
- `node.clipText = true`
- `node.clipText = false`

## 구현
두 노드에 같은 크기를 적용하고 `clipText` 값만 다르게 설정합니다.

## 실행 결과
첫 노드는 경계를 기준으로 텍스트를 자르고, 두 번째 노드는 일반 렌더링을 사용합니다.

## 검증 기준
노드 2개, 연결선 0개이며 두 표현의 차이가 보여야 합니다.

## 주의점
텍스트 크기, 패딩, 정렬도 실제 잘림 영역에 영향을 줍니다.

## 다음 단계
