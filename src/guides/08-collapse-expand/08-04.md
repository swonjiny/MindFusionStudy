# 08-04 전체 접기

## 학습 목표
트리의 모든 가지를 한 번에 접어 최상위 루트만 남깁니다.

## 사용 API
- `Diagram.nodes`
- `Diagram.links`
- `expandable`, `expanded`, `visible`

## 구현 순서
루트를 제외한 모든 노드를 숨기고, 모든 연결선을 숨긴 뒤 펼침 가능한 노드의 expanded를 false로 설정합니다.

## 실행 결과
7개 노드 트리가 루트 1개 표시로 축약됩니다.

## 검증 기준
전체 노드 7개·연결선 6개, visible 노드 1개·연결선 0개, expanded 노드 0개입니다.

## 활용
대규모 트리에서 개요만 먼저 보여주거나 초기 화면을 단순화할 때 유용합니다.
