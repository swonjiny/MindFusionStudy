# 06-03 자식 5개

## 학습 목표
배열 반복으로 부모 1개에 자식 5개를 연결합니다.

## 사용 API
- `ShapeNode`
- `createDiagramLink`
- 배열 반복문

## 구현 순서
루트를 먼저 만든 뒤 5회 반복하며 자식 생성과 연결을 한 번에 수행합니다.

## 실행 결과
하나의 부모에서 다섯 개 자식으로 연결선이 방사됩니다.

## 검증 기준
노드 6개, 연결선 5개가 모두 visible이고 펼친 부모가 1개여야 합니다.

## 설계 팁
자식 수가 늘어나면 수동 좌표보다 다음 장의 `TreeLayout`을 사용하는 편이 안전합니다.
