# 09-02 HTML 제목과 설명

## 목표

ControlNode 템플릿에 `article`, `h3`, `p`를 넣어 제목과 설명을 구조화합니다.

## 구현

`onControlLoaded`에서 `ref.current.find()`로 코어 View를 얻은 뒤 노드를 생성합니다.
템플릿은 한 문자열 안에 모든 스타일을 포함하므로 다른 프로젝트로 파일 하나만 복사해도 동작합니다.

`onNodeDomCreated` 전에는 콘텐츠 DOM이 보장되지 않습니다. 이벤트 인자의 노드에서
`getContent()`를 호출한 다음 `[data-mf-html-node="09-02"]`를 검색합니다.

## 정상 결과

- ControlNode 1개, HTML 루트 1개, 연결선 0개
- 제목과 설명이 흰 카드 안에 표시
- 콘솔 오류 0개
