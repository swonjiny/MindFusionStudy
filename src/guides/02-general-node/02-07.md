# 02-07 노드 크기 변경

## 1. 학습 목표

bounds의 width와 height를 읽고 위치를 유지한 채 노드 크기를 바꾼다.

## 2. 완성 화면

현재 bounds Tag와 `노드 크게 만들기` 버튼이 보이며 클릭할 때 노드가 넓고 높아진다.

## 3. 선수 지식

02-06에서 Rect를 새로 할당해 위치를 변경한 방식을 이해해야 한다.

## 4. 이번 단계에서 사용하는 객체

`ShapeNode.bounds`, `Rect.width`, `Rect.height`를 사용한다.

## 5. 핵심 개념

크기만 바꿀 때 x와 y는 보존한다. 텍스트가 길면 충분한 width와 height가 필요하다.

## 6. 파일 구성

`Step0207NodeSize.jsx`, `DiagramLesson.jsx`의 `resizeNode` 함수가 핵심이다.

## 7. 구현 순서

노드 조회 → 기존 bounds 읽기 → width+12, height+8 계산 → 새 Rect 할당 → metrics 갱신 순서다.

## 8. 전체 소스 코드

```js
node.bounds = new Rect(
  node.bounds.x,
  node.bounds.y,
  node.bounds.width + 12,
  node.bounds.height + 8,
);
```

## 9. 소스 코드 상세 설명

x와 y를 그대로 사용해 좌측 상단 기준점을 고정하고 오른쪽과 아래 방향으로 크기를 늘린다.

## 10. 실행 흐름

버튼 → 크기 계산 → bounds setter → DiagramView repaint → Tag 갱신 순서다.

## 11. 상태와 데이터 흐름

Diagram이 실제 크기를 보관하고 React는 사용자가 읽을 정수형 표시값만 관리한다.

## 12. 정상 실행 기준

클릭마다 width 12, height 8이 증가하고 x, y와 노드 수는 유지되어야 한다.

## 13. 자동 검증 방법

버튼 클릭 전후 Tag의 w, h 값이 증가하는지 확인한다.

## 14. 수동 확인 항목

테두리가 깨지지 않고 텍스트가 새 크기 중앙에 유지되는지 확인한다.

## 15. 자주 발생하는 오류

너비나 높이를 0 또는 음수로 만들면 노드가 보이지 않거나 조작하기 어려워진다.

## 16. 오류 해결 과정

최솟값을 적용하고 현재 width/height를 화면이나 console에서 먼저 확인한다.

## 17. 이전 단계와 비교

02-06은 x, y를 변경했고 이번 단계는 width, height만 변경한다.

## 18. 다음 단계

02-08에서 노드 안의 한글 텍스트, 색상과 글자 크기를 설정한다.

## 19. 연습 문제

작게 만들기 버튼과 최소 너비/높이 제한을 추가한다.

## 20. 핵심 요약

크기는 bounds의 width와 height이며 위치를 유지하려면 x와 y를 그대로 복사한다.
